# Sauber & Rein - Gebäude- und Hausmeisterservice Regensburg

Professionelle Website für **Sauber & Rein**, einen Gebäudereinigungs- und Hausmeisterservice mit Sitz in Regensburg, Bayern.

## Technologie

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**

## Entwicklung

```bash
npm install
npm run dev
```

Die Entwicklungsumgebung ist unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Inhalt

- Startseite mit Hero-Bereich, Leistungsübersicht, Über-uns-Sektion und Kontaktbereich
- Responsive Design (mobile-first)
- SEO-optimierte Metadaten
- Deutsche Sprache
